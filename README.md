# 🎯 Number Guessing Game (Python)

A simple command-line Number Guessing Game built in Python. The player selects a difficulty level, tries to guess a randomly generated number within a limited number of attempts, and receives hints after each guess.

---

## 📌 Features

- 👤 Player registration (Name & Age)
- 🎲 Random number generation
- 🎯 Three difficulty levels:
  - Easy
  - Medium
  - Hard
- 🔢 Limited number of attempts based on difficulty
- 📈 Hint system:
  - Near High
  - Too High
  - Near Low
  - Too Low
- ✅ Input validation using exception handling
- 🔁 Play Again option
- 📝 Stores all guesses in a list

---

## 🎮 Game Rules

- Enter your name and age.
- Select a difficulty level.
- Guess the hidden number.
- You have a limited number of attempts.
- After each incorrect guess, the game provides a hint:
  - Near High
  - Too High
  - Near Low
  - Too Low
- Win by guessing the correct number before running out of attempts.
- Choose whether to play another round.
